# yaait

`yaait` tracks AI usage and remaining budgets across providers. Each named
tracker represents one subscription or API account, so you can keep personal
and work usage separate even when both use the same provider.

Start with [installation](install.md), then [add a tracker and check usage](usage.md).

## Supported providers

| Provider | Reports | Setup |
| --- | --- | --- |
| Claude Code | Subscription windows, reset times, and extra usage budget | [Claude Code](providers/claude-code.md) |
| Codex | 5-hour and weekly limits, reset times, and credits | [Codex](providers/codex.md) |
| DeepSeek | API account balances in USD and CNY | [DeepSeek](providers/deepseek.md) |
| GitHub Copilot | Request quota and reset time | [GitHub Copilot](providers/github-copilot.md) |
| LiteLLM | Spend, tokens, requests, and key or user budget | [LiteLLM](providers/litellm.md) |
| OpenRouter | API key spend and remaining key budget in USD | [OpenRouter](providers/openrouter.md) |
