# Claude Code plan tracker

Status: researched, experimental

This feature adds an experimental `claude-code-plan` provider for Claude Pro,
Max, Team, and Enterprise subscription windows. Anthropic does not currently
publish a supported machine-readable subscription usage API, so this provider
has a higher maintenance risk than the LiteLLM and Codex providers.

- [Specification](spec.md)
- Implementation should follow the supported LiteLLM and Codex integrations.
